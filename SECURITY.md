# Security reports

Do not report a suspected vulnerability through a public issue, discussion, or attachment.
Use GitHub's [private vulnerability report](https://github.com/ahmet12/branchline-releases/security/advisories/new)
for this repository. A GitHub account is required. This channel is for security reports,
not activation or purchase support; see [Support](SUPPORT.md) for other questions.

Describe the affected version, the impact, and a minimal reproduction without real
credentials or private repository contents. Do not include usable access tokens or license keys.

No application version has been publicly distributed yet. Supported release versions and
security-update guidance will be recorded here when distribution starts. There is no
paid bug-bounty program or guaranteed response time.
