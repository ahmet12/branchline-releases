# Usage and licensing

Branchline is proprietary software developed by Ahmet Kılıç under the independent
developer brand Kylindravia. This public repository contains downloads, product information
and feedback; the application source is maintained separately.

## Personal access

The official release can be [downloaded publicly](https://github.com/ahmet12/branchline-releases/releases/latest).
Using it requires an individual activation code provided privately by the developer.
Current free personal access lasts **180 days from first successful activation on one
active Mac**. Downloading a package does not grant a license or start the access period.

First activation requires internet access. Activated access works offline until its
recorded expiry. Reinstalling, updating or changing Macs does not restart that period.
Deactivate the old Mac before activating another; contact private support if it is unavailable.

There is no required beta program, feedback obligation, public trial, paid checkout,
automatic subscription or entitlement to a future paid license. GitHub login is not
required for app activation; a GitHub account is needed to post an issue.

## Optional stability reporting

Branchline 0.4.1 adds **Settings → Diagnostics**. Reporting is off by default and
independent of licensing. If enabled, technical crash reports and macOS-provided hang
and performance diagnostics go to Kylindravia's Sentry project in the EU.

Reports include application/macOS versions, device architecture/model, technical stack
traces and recent Git operation types. Repository names, branch names, paths, source code,
diffs, terminal output, arbitrary error messages, credentials and license details are
excluded. Screenshots and session recording are disabled. The service receives connection
metadata during delivery; project settings disable stored IP addresses and remove derived
geography. Reports are retained for up to 30 days on the free plan.

Turning reporting off stops collection and discards pending local reports. It cannot
recall reports already sent. macOS controls hang diagnostics, so not every freeze or
force quit generates a report. **Send Test Report** checks the connection without crashing
the app and provides a report ID. Contact [private support](SUPPORT.md#private-support)
for report-related requests; never post private diagnostic exports in public Issues.

The linked versioned privacy notices give the complete provider and data-handling details.
